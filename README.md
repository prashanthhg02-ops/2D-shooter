# Starfall

A small, browser-based 2D arcade shooter built with HTML, CSS, and JavaScript. It uses the HTML canvas API and has no external dependencies or build step.

## Play

Open `index.html` in a modern web browser, then select **Launch mission**.

## Controls

| Action | Keyboard | Touch |
| --- | --- | --- |
| Move | `WASD` or arrow keys | Drag on the game field |
| Fire | Hold `Space` | Touch and drag |
| Pause / resume | `P` / `Enter` | Use the on-screen button |

## Gameplay

- Shoot enemy drones to earn points and survive increasingly difficult waves.
- Avoid enemies and their projectiles; you have three shields.
- Collect cyan power-ups for a temporary rapid-fire boost.
- When the mission ends, select **Play again** to restart.
